**Project Title**: **ADVISING** – **A**utonomic **D**ysfunction using **V**ital-sign **I**ndicators to **S**ubtype via **I**ntegrated **N**euroanalytics for **G**uidance

**Date**: May 13, 2026

This repository contains a Center for Analysis (CfA) Method Tutorial based on the ADVISING study, developed by researchers from the TRANSCENDENT program.

The purpose of this tutorial is to provide a transparent, step-by-step guide to applying agglomerative hierarchical clustering to identify latent subgroups in multimodal autonomic data. The workflow is designed for clinical and translational researchers interested in moving beyond binary classifications toward data-driven phenotyping approaches.

**Repository Contents**

This tutorial includes the following components:

* ADVISING study description [study\_description.txt]

Background, objectives, and rationale for the analytic approach

* Analysis pipeline overview [analysis\_pipeline\_overview.txt]

Step-by-step description of data preprocessing, clustering, and validation

* R code [zemek\_cfa\_code.Rmd]

Reproducible script implementing the full analytical workflow
