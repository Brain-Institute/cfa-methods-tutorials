# Error-Feedback Guided Refinement (EFGR) Post-Processing

[cite_start]This repository contains MATLAB scripts that implement **Error-Feedback Guided Refinement (EFGR)** methods to improve super-resolved MRI images generated by an EDSR network[cite: 8]. [cite_start]The refinement enforces low-resolution consistency while adaptively correcting errors in both spatial and frequency domains[cite: 9].

---

## 1. Key Features
* [cite_start]**Post-Processing Only:** These methods do not require retraining the super-resolution network[cite: 10].
* [cite_start]**Adaptive Correction:** Uses spatial ($\alpha$) and frequency ($\beta$) maps to modulate correction strength based on image structure[cite: 20, 21, 25].
* [cite_start]**Automated Conversion:** Grayscale images are automatically converted to 3-channel (RGB) format[cite: 15].

---

## 3. Code 1: EFGR – Analysis Version

### Description
[cite_start]This script evaluates the EDSR output alongside spatial-only (A-EFGR) and frequency-only (F-EFGR) refinement frameworks[cite: 18, 28, 30, 31]. 

The correction strength is modulated by:
* [cite_start]**Spatial structure ($\alpha$ map):** Uses gradient magnitude to identify edges[cite: 21, 22]. [cite_start]It applies strong correction in smooth regions and weak correction near anatomical boundaries[cite: 23, 24].
* [cite_start]**Frequency content ($\beta$ map):** Uses Laplacian response to estimate local high-frequency energy[cite: 25, 26]. [cite_start]It applies less correction in high-frequency regions to prevent over-sharpening[cite: 27].

### How to Run
1. [cite_start]Save the script as `FA_EFGR_Analysis.m`[cite: 43, 44].
2. [cite_start]Place the four required PNG images listed above in the same folder[cite: 45].
3. [cite_start]Open MATLAB and set the current folder to this directory[cite: 46].
4. Run the following command in the Command Window:
   ```matlab
   FA_EFGR_Analysis
   [cite_start]``` [cite: 47, 48]

### Outputs
[cite_start]While no files are saved to the disk, the script generates[cite: 33, 34]:
* [cite_start]**Printed Values:** PSNR and SSIM metrics for evaluation[cite: 32, 41].
* [cite_start]**Visual Figures:** Results for EDSR, spatial-only refinement, and frequency-only refinement, as well as the spatial $\alpha$-map and frequency $\beta$-map[cite: 35, 36, 37, 38, 39, 40].
